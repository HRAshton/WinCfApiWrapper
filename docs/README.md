# Documentation

WinCfApiWrapper is a Windows-only .NET library exposing read-only, container-backed Cloud Files sync roots.

| Guide | Audience | Contents |
| --- | --- | --- |
| [Architecture](architecture.md) | Maintainers and advanced integrators | Components, mount lifecycle, hydration, and errors |
| [Containers](containers.md) | Library consumers | Implementing `IContentContainer`; built-in formats and source contracts |
| [Security model](security-model.md) | Consumers and reviewers | Trust boundaries, limitations, and threat scenarios |
| [Security assessment](security-assessment.md) | Security reviewers | Threat scenarios, reviewed controls, residual risks, and follow-up actions |
| [Development](development.md) | Contributors | Windows prerequisites, build, tests, and coverage |
| [Releasing](releasing.md) | Maintainers | Release pipeline, attestation, verification, and recovery |

For installation, a basic usage example, and the public API, see the [project README](../README.md), which is also included in the NuGet package. For contribution rules, see [CONTRIBUTING.md](../CONTRIBUTING.md). Vulnerabilities belong in the private channel described by [SECURITY.md](../SECURITY.md).
